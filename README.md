# Maquetado de interfaz - Página web de cursos

## Descripción

Este proyecto consiste en el maquetado de una página web enfocada en cursos en línea. El objetivo de la actividad fue practicar la creación de interfaces web, la organización de contenido y la estructura de diferentes páginas que forman parte de un mismo sitio.

Durante el desarrollo se realizaron cuatro interfaces principales:

- **Index:** página principal del sitio.
- **Gallery:** galería donde se muestran los cursos disponibles.
- **Contacto:** apartado destinado a la información y formulario de contacto.
- **Acerca del sitio:** sección donde se presenta información general sobre el sitio y su propósito.

El proyecto se enfoca principalmente en el diseño y maquetado de las interfaces, buscando que cada sección tenga una estructura clara, organizada y fácil de utilizar.

## Objetivo

Diseñar y maquetar una página web de cursos mediante la creación de diferentes interfaces, aplicando conocimientos de estructura HTML, estilos CSS y organización de los elementos visuales.

## Interfaces desarrolladas

### 🏠 Index

Es la pantalla principal del sitio. En ella se presenta la página de cursos y se proporciona acceso a las diferentes secciones mediante la navegación.

### 📚 Gallery

En esta sección se presenta una galería de cursos disponibles, organizados mediante tarjetas para facilitar su visualización.

### 📩 Contacto

Esta interfaz permite mostrar información relacionada con el contacto y proporciona un espacio para que los usuarios puedan comunicarse con el sitio.

### ℹ️ Acerca del sitio

Sección destinada a proporcionar información sobre el propósito del sitio y la página de cursos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
